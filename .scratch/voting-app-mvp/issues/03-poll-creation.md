# 03: 폴 생성 (운영자 전용)

**What to build:** 운영자 권한이 있는 계정만 접근 가능한 폴 생성 화면. 질문과 선택지 외에 단일/다중 선택 여부, 마감일 또는 무기한, 결과 공개 방식(실시간/마감 후 공개)을 생성 시점에 지정한다.

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 운영자 권한이 없는 계정은 폴 생성 화면에 접근할 수 없음
- [ ] 운영자는 질문과 2개 이상의 선택지를 입력해 폴을 생성 가능
- [ ] 생성 시 단일 선택/다중 선택 여부를 지정 가능
- [ ] 생성 시 마감일(특정 일시) 또는 "무기한"을 지정 가능
- [ ] 생성 시 결과 공개 방식(실시간/마감 후 공개)을 지정 가능
- [ ] 생성된 폴은 공개 목록에서 확인 가능
