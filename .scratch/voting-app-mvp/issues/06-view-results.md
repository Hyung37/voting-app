# 06: 결과 보기

**What to build:** 로그인 여부와 무관하게 누구나 폴의 결과 화면을 볼 수 있다. 폴의 결과 공개 설정(실시간/마감 후 공개)에 따라 표시 시점과 갱신 방식이 달라진다.

**Blocked by:** 05

**Status:** ready-for-agent

- [ ] 로그인 없이 누구나 폴 결과 화면에 접근 가능
- [ ] "실시간 공개" 폴은 접속 즉시 현재 집계를 보여주고, 페이지가 열려 있는 동안 1분마다 자동으로 다시 불러와 최신 집계로 갱신됨
- [ ] "마감 후 공개" 폴은 마감(자동 또는 수동) 전에는 집계 결과가 보이지 않고, 마감 후에만 최종 집계가 보임
