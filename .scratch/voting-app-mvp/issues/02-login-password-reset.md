# 02: 로그인 + 비밀번호 찾기

**What to build:** 이메일 인증을 완료한 계정이 이메일+비밀번호로 로그인하고, 이후 요청에서 "현재 로그인한 계정"을 식별할 수 있는 세션. 비밀번호를 잊으면 이메일로 재설정할 수 있는 흐름.

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 이메일 인증을 완료한 계정은 이메일+비밀번호로 로그인 가능
- [ ] 이메일 인증 전 계정은 로그인 거부
- [ ] 비밀번호를 잊은 경우 이메일로 재설정 링크를 요청 가능
- [ ] 재설정 링크를 통해 새 비밀번호를 설정 가능
- [ ] 로그인 세션이 유지되어 이후 요청에서 현재 로그인한 계정을 식별 가능
