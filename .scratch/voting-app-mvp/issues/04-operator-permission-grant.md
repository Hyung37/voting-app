# 04: 운영자 권한 부여/회수

**What to build:** 운영자만 접근 가능한 사용자 목록/권한 관리 화면에서, 기존 운영자가 다른 사용자 계정에 운영자 권한을 즉시 부여하거나 회수할 수 있다. 대상자의 별도 동의 절차는 없다.

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 운영자만 사용자 목록/권한 관리 화면에 접근 가능
- [ ] 운영자가 다른 사용자 계정에 운영자 권한을 부여하면 즉시 반영되어 대상 계정이 운영자 전용 화면에 접근 가능해짐
- [ ] 운영자가 다른 운영자의 권한을 회수하면 즉시 반영됨
- [ ] 대상자의 별도 동의 절차 없이 적용됨
