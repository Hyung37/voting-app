# 07: 폴 수정/삭제(휴지통 이동)

**What to build:** 투표가 0건인 폴은 운영자가 질문/선택지/설정을 자유롭게 수정할 수 있다. 투표가 1건이라도 존재하면 수정은 불가능하고, 삭제(휴지통으로 이동)만 가능하다. 투표 여부와 무관하게 삭제는 항상 가능하다.

**Blocked by:** 03, 05

**Status:** ready-for-agent

- [ ] 투표가 0건인 폴은 운영자가 질문/선택지/설정을 자유롭게 수정 가능
- [ ] 투표가 1건이라도 존재하면 수정 화면/기능이 비활성화됨
- [ ] 운영자는 투표 여부와 무관하게 언제든 폴을 삭제(휴지통으로 이동)할 수 있음
- [ ] 휴지통으로 이동한 폴은 공개 목록과 투표/결과 화면에서 즉시 사라짐
