# 01: 회원가입 + 이메일 인증

**What to build:** 이메일, 비밀번호, 이름, 생년월일로 가입 신청하면 Resend로 인증 메일이 발송되고, 인증 링크를 클릭해야 계정이 활성화되는 흐름. 같은 이름+생년월일 조합으로 이미 가입된 계정이 있으면 가입을 거부한다.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 이메일, 비밀번호, 이름, 생년월일을 입력해 가입 신청 가능
- [ ] 가입 신청 시 이메일 인증 링크가 발송됨 (Resend)
- [ ] 인증 링크를 클릭하기 전까지 계정은 비활성 상태로 남음
- [ ] 이미 같은 이름+생년월일 조합으로 가입된 계정이 있으면 가입 거부
- [ ] 같은 이메일로 중복 가입 불가
