# 08: 휴지통: 복원/영구 삭제

**What to build:** 운영자 전용 휴지통 화면에서, 휴지통에 있는 폴을 영구 삭제하거나 복원할 수 있다. 영구 삭제는 되돌릴 수 없다. 복원은 질문과 선택지만 되살리고 기존 투표 데이터는 모두 지운다.

**Blocked by:** 07

**Status:** ready-for-agent

- [ ] 운영자만 휴지통 목록에 접근 가능
- [ ] 휴지통의 폴을 영구 삭제하면 질문/선택지/투표 데이터가 모두 사라지고 되돌릴 수 없음
- [ ] 휴지통의 폴을 복원하면 질문과 선택지만 되살아나고 기존 투표 데이터는 모두 삭제됨
- [ ] 복원된 폴은 투표 0건 상태이므로 다시 자유롭게 수정 가능한 상태로 돌아감 (07의 수정 규칙 적용)
