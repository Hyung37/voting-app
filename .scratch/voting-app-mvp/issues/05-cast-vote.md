# 05: 투표하기

**What to build:** 로그인한 계정이 열려있는 폴에 투표한다. 투표 기록에는 어떤 계정이 투표했는지 남지 않으며, 오직 "이 계정이 이 폴에 투표했는지 여부"만 별도로 확인해 중복 투표를 막는다 (docs/adr/0001 참고). 폴의 단일/다중 선택 설정, 마감 상태(수동 마감 또는 마감일 경과)에 따라 투표 가능 여부가 결정된다.

**Blocked by:** 03, 02

**Status:** ready-for-agent

- [ ] 로그인한 계정만 투표 가능
- [ ] 마감되었거나(수동 마감 포함) 마감일이 지난 폴에는 투표 불가
- [ ] 단일 선택 폴은 옵션 하나만, 다중 선택 폴은 여러 옵션을 선택해 제출 가능
- [ ] 같은 계정은 같은 폴에 두 번 투표할 수 없음
- [ ] 투표 기록 자체에는 어떤 계정이 투표했는지 남지 않음 — 운영자를 포함해 누구도 특정 계정이 무엇을 선택했는지 조회할 수 없음
